## Goal

Keep the authorized patrol moving toward demonstrated analyzer corrections. Complete useful work; do not optimize for fewer reports or more audits.

## Constraints

User instructions and grants control. Allow one implementation/refresh/maintenance worker and two patrol PRs. Preserve real effects, proof pauses, and repository controls.

Honor operator holds at their stated scope. A PR's unknown gate blocks that merge; do not turn it into a global stop. Substantive soundness objections or medium/high risk still need disposition before automatic chaining.

## Done check

Use the state file as an index; verify the live facts needed for this event. Resume existing owners and reviews first. Launch promptly when capacity permits and a source witness suggests a contract mismatch. After no-fix, choose a different supported lead. With none, record the examined scope and end; a timer is not new evidence.

Bind new T3 workers to a unique worktree from origin/master and reserve the slot first. Reconcile a lost launch before retrying; release capacity only after owned work stops. Update existing PRs through their owner and branch.

## Evidence

Use the [trusted-base repository gate](../../docs/change-risk.md), never the merge-risk skill. Merge only with authority, LOW on the exact base/head, required reviews/checks, semantic evidence, and an expected-head guard. No bypass; a static LOW is not merge permission.

Count corrected false positives, direct/inherited unknowns, attribution repairs, and restored true effects separately. No-fix reduces nothing. Reuse evidence whose inputs still match.

## Handoff

Use the [worker brief](references/worker-brief.md) only when assigning work. Link PRs; save decision changes atomically and deduplicate late reports. Start eligible work before app CI watching, then end without polling. Unwatch completed work or handback. Leave schedules unchanged. Report the result and next action briefly, without repeating unchanged history.
